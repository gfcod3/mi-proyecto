# 🚀 Hoja de Ruta: Dominando Git (Proyecto: Mi Proyecto)

## ✅ Nivel 1: Fundamentos (Lo que ya hemos hecho)

[x] Inicializar un repositorio (git init)
[x] Ver el estado de los archivos (git status)
[x] Agregar archivos al área de preparación (git add .)
[x] Crear un "snapshot" o guardado (git commit -m "...")
[x] Ver el historial de cambios (git log --oneline)
## 🟡 Nivel 2: Manejo de Errores y Recuperación (Lo que acabamos de aprender)

[x] Identificar la creación de un archivo (git show <ID_creacion>)
[x] Identificar el borrado de un archivo (git show <ID_borrado>)
[x] Usar git revert para deshacer un cambio específico sin perder historial
[x] Interpretar diffs: +, -, @@, index, new file
[x] Resolver conflictos de autenticación en entornos remotos (403 Error)
## 🔵 Nivel 3: Gestión de Ramas (Próximo paso lógico)

[ ] Crear una rama nueva (git branch <nombre>)
[ ] Cambiar entre ramas (git checkout o git switch)
[ ] Fusionar ramas (git merge)
[ ] Eliminar ramas ya usadas (git branch -d)
## 🟣 Nivel 4: Trabajo Remoto Avanzado

[ ] Conectar con GitHub (git remote add origin ...)
[ ] Empujar cambios (git push)
[ ] Traer cambios del equipo (git pull)
[ ] Trabajar con forks y Pull Requests
## ⚫ Nivel 5: Limpieza y Optimización

[ ] Ignorar archivos que no deben subir (.gitignore)
[ ] Limpiar archivos temporales (git clean)
[ ] Reescribir historia limpia (git rebase - Avanzado)
